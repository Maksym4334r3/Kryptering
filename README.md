# Kryptografiverktøy

En enkel Svelte-nettside for å kryptere og dekryptere tekst med Caesar, Vigenère og One-Time Pad. One-Time Pad genererer en tilfeldig demonstrasjonsnøkkel ved kryptering.

## Start prosjektet

```sh
npm install
npm run dev
```

One-Time Pad bruker `Math.random()` og er kun ment for demonstrasjon, ikke for reell sikkerhet.
